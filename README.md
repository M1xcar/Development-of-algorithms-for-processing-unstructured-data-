## 📌 Описание проекта
В рамках курсовой работы исследовались методы обработки неструктурированных данных (изображений) с использованием глубокого обучения[cite: 3]. Была разработана и обучена свёрточная нейронная сеть (`CNNClassifier`) на базе библиотеки **PyTorch** для бинарной классификации одежды (футболки и джинсы).

### Основные результаты:
* **Архитектура:** Свёрточная нейронная сеть с BatchNorm, MaxPooling и Dropout слоями.
* **Точность (Test Accuracy):** ~98% на тестовой выборке.
* **Метрики качества:** Accuracy, Precision, Recall, F1-score, матрица ошибок (Confusion Matrix).
